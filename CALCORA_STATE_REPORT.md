## 5. Defect Found and Fixed This Session

**Symptom:** `fact(5)` → `Error: Unrecognized function: fact`, while `5!` and `factorial(5)`
both evaluated correctly.

**Root cause:** the RPN evaluator's function allowlist and dispatch switch enumerated
`factorial` but not its `fact` alias, so the alias was rejected before evaluation.

**Fix:** added `'fact'` to the unary-function allowlist and a `case 'fact':` fallthrough
alongside `case 'factorial':` in `src/engine/mathEngine.ts`.

**Regression test:** `tests/mathEngineRegression.test.ts` now asserts `fact(5) = 120`,
`fact(0) = 1`, `factorial(5) = 120`, `5! = 120`.

**Not claimed:** postfix word forms (`5 fact`, `5 sin`, `5 sqrt`) remain unsupported. That is
uniform, pre-existing tokeniser behaviour — a bare word after a number is read as implicit
multiplication — and applies identically to every function. Nothing in the codebase emits that
form, so it is recorded as a limitation rather than "fixed".
